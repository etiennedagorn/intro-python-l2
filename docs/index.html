Installer Python et VS Code

Pour suivre le cours dans de bonnes conditions, il faut idéalement installer trois éléments : Python, Visual Studio Code et l'extension Python de VS Code.

Python
le langage et le programme qui exécute vos fichiers .py.
VS Code
l'éditeur dans lequel vous écrivez, sauvegardez et organisez vos scripts.
Extension Python
le module qui aide VS Code à reconnaître Python, choisir l'interpréteur et lancer le fichier.

Sur Windows, cochez l'option Add Python to PATH si elle apparaît pendant l'installation. Cela permet de lancer Python depuis le terminal sans réglage supplémentaire.

Windows

  1. Télécharger Python depuis python.org/downloads.
  2. Choisir la version stable de Python 3 proposée par le site. En septembre 2026, c'est Python 3.14 ; éviter les versions indiquées comme préversions.
  3. Lancer l'installateur, cocher Add Python to PATH si l'option apparaît, puis choisir l'installation recommandée.
  4. Télécharger VS Code depuis code.visualstudio.com/download.
  5. Dans VS Code, ouvrir les extensions, chercher Python et installer l'extension Microsoft : ms-python.python.

macOS

  1. Télécharger Python depuis python.org/downloads et ouvrir le fichier .pkg.
  2. Choisir l'installation standard. Après installation, utiliser plutôt la commande python3 que python.
  3. Télécharger VS Code depuis code.visualstudio.com/download, puis placer l'application dans le dossier Applications.
  4. Installer l'extension Python de Microsoft depuis l'onglet Extensions de VS Code.
  5. Si VS Code demande de choisir un interpréteur, sélectionner la version associée à Python 3.

Tablette ou Chromebook

Un ordinateur portable ou un poste de l'université reste la solution recommandée pour l'ensemble du semestre, surtout à partir des TD avec fichiers, graphiques et CSV.

Sur tablette, VS Code n'est pas disponible comme application de bureau classique. vscode.dev peut servir à lire et écrire des fichiers dans le navigateur, mais il ne remplace pas toujours un environnement Python local.

En solution de secours, les premiers exercices peuvent être préparés dans un environnement Python en ligne, par exemple Google Colab, puis repris sur un ordinateur en TD. Les exercices qui manipulent des dossiers, des fichiers .py, des exports .png ou des CSV seront plus fiables sur ordinateur.

Premiers gestes avec VS Code

  1. Créer un dossier pour le cours, par exemple Python_L2.
  2. Ouvrir VS Code, puis choisir File > Open Folder et sélectionner ce dossier.
  3. Créer un nouveau fichier et l'enregistrer sous test.py. Le suffixe .py indique qu'il s'agit d'un fichier Python.
  4. Écrire le code ci-dessous, sauvegarder le fichier, puis l'exécuter.
print("Bonjour Python !")

Si tout fonctionne, le message Bonjour Python ! apparaît dans le terminal. Sauvegarder et exécuter sont deux actions différentes : sauvegarder écrit les changements dans le fichier, exécuter demande à Python de lire ce fichier.

Ça ne fonctionne pas ?

  • Python n'est pas détecté. Fermer puis rouvrir VS Code ; sur Windows, vérifier l'option PATH ou essayer la commande py.
  • VS Code demande un interpréteur. Choisir une version Python 3 dans la liste.
  • Le fichier ne s'exécute pas. Vérifier qu'il s'appelle bien test.py et pas test.py.txt.
  • Le fichier est introuvable. Regarder le dossier ouvert dans VS Code et le dossier où le fichier a été enregistré.

Les cas plus complexes pourront être réglés pendant la première séance.
