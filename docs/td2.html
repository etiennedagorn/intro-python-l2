Boucles, conditions et proportions avec données OWID

Parcourir une liste de dictionnaires, classer des observations, compter une proportion et construire un graphique CO2 avec matplotlib.

  • Boucles
  • Conditions
  • Dictionnaires
  • Graphique CO2

Objectifs

  • Comprendre comment une observation peut être représentée par un dictionnaire.
  • Utiliser une boucle for pour appliquer la même action à plusieurs pays.
  • Écrire une condition et calculer une proportion.
  • Préparer deux listes pour tracer un graphique sans notion nouvelle inutile.

Déroulé actif

  1. Observer un dictionnaire, puis une liste de dictionnaires.
  2. Prédire et modifier les affichages.
  3. Compléter une classification avec if/elif/else.
  4. Utiliser un compteur, puis représenter les valeurs avec plt.bar.
  5. Déboguer des erreurs d'indentation et de compteur.
Point de vigilance. Le graphique réutilise exactement la boucle déjà travaillée : construire une liste de pays, construire une liste de valeurs, puis tracer.
