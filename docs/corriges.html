Exécuter les corrigés

Python 3 avec matplotlib suffit pour les TD1 à TD4. Le TD5 utilise aussi pandas. Installer les bibliothèques dans le Python choisi par VS Code, puis ouvrir le dossier extrait et lancer le script depuis ce dossier. Pour les notebooks, sélectionner ce même Python dans Jupyter et exécuter les cellules dans l’ordre depuis un noyau redémarré.

Les données sont celles du dépôt. Les simulations peuvent varier ; les résultats du TD5 sont fixés par les copies CSV fournies. Les noms de fichiers des énoncés et leurs données restent inchangés.
