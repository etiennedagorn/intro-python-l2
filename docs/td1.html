TD1

Premiers scripts et statistiques descriptives simples

Créer un fichier Python, l'exécuter depuis le bon dossier, manipuler des variables et produire un premier graphique avec matplotlib.

  • Fichier .py
  • Variables
  • Listes
  • Premier graphique

Objectifs

  • Créer, sauvegarder et exécuter un script Python.
  • Comprendre la différence entre texte, nombre et liste.
  • Lire une erreur simple : syntaxe, nom inconnu, type incompatible.
  • Transformer une liste de valeurs en graphique sauvegardé.

Déroulé actif

  1. Lire et prédire le résultat de petits fragments.
  2. Modifier un script minimal et vérifier le fichier exécuté.
  3. Compléter les calculs de moyenne, minimum et maximum.
  4. Tracer une figure simple avec plt.bar.
  5. Rédiger trois phrases d'interprétation prudente.
Point de vigilance. Le graphique est volontairement guidé : il sert d'abord à installer le geste importer, tracer, nommer les axes, sauvegarder.
